# Demo project — local glossary

A project-local reference. Scope of reuse decides tier: a term useful to every project belongs
in core-vault's Tier 2; a term meaningful only here stays project-local, in `03-references/`.

- **Composed scope** — the union of a project vault and everything its manifest inherits, indexed
  together and retrieved across as one.
- **Spine** — the denormalised provenance and status fields carried on every chunk, so a passage
  can state whether it is current without a join.
